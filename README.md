## 2. Strict Design System

### 2.1 Solid 5-Colour Palette
- **Pure White (`#FFFFFF`):** Main backgrounds and primary light surfaces.
- **Soft Ivory (`#F3F3F1`):** Alternating content sections and subtle contrast.
- **Obsidian Black (`#111111`):** Dark hero sections, headings, navigation bar, and global footer.
- **Charcoal (`#292929`):** Cards, dark containers, and secondary surfaces.
- **Neutral Grey (`#777777`):** Secondary text, subtle dividers, and metadata.

*Strictly Zero Gradients, Zero Glassmorphism, Zero AI-style Blobs, Zero Emojis.*

### 2.2 Typography
- **Headings & Editorial Quotes:** `Playfair Display` (Google Fonts)
- **Body & UI Elements:** `Manrope` (Google Fonts)

### 2.3 Brand Reveal Opening Animation
A signature 1.85s brand sequence (white emblem, `VACHAAN.` typography, hairline divider, and tagline reveal) is active on every page load and refresh across all six pages, transitioning into each section. Clicking anywhere immediately bypasses the animation.

### 2.4 Cross-Device Responsive Architecture
Verified across 11 core viewport standards (from 320×568 up to 1920×1080) with zero horizontal overflow:
- **Ultra-Small Smartphones (320px–360px):** Single-column reflow, touch-friendly wrapping buttons, compact 64px header, and fluid typography.
- **Modern Smartphones (375px–414px):** 44px+ touch targets, responsive table wrappers, and adaptive form embeds.
- **Tablets & iPads (768px–1024px):** 2-column balanced editorial grids, accessible hamburger drawer navigation, and clean sidebars.
- **Laptops & Desktops (1200px–1920px):** Proportional full-width navigation, multi-column editorial split layouts, and generous white space.

## 5. GitHub Pages Deployment Guide

This project is built 100% with static, client-side technologies (HTML5, CSS3, ES6+ Vanilla JavaScript) and is natively optimized for GitHub Pages.

### Step 1: Initialize Git & Commit
```bash
git init
git add .
git commit -m "Initial commit: VACHAAN official website"
```

### Step 2: Push to GitHub
```bash
git remote add origin https://github.com/<your-username>/<repo-name>.git
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. Your website will be live in a few minutes at `https://<your-username>.github.io/<repo-name>/`.

### Custom Domain (Optional)
If connecting a custom domain (e.g. `vachaan.co`):
1. In the GitHub Pages settings, enter your domain under **Custom domain**.
2. Check **Enforce HTTPS**.
3. A `CNAME` file will automatically be created in the repository root.
